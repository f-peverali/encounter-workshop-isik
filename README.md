# encounter-workshop-isik
Gemeinsamer Arbeitsbereich für den Encounter-Workshop: Versorgungsszenarien und Journey-Skizzen sammeln, Zuordnungen zu Kontaktebenen festhalten und offene Fragen sowie mögliche Modellierungsimplikationen dokumentieren. Die Ergebnisse dienen der weiteren fachlichen Diskussion.
